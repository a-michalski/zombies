STARY SYSTEM - PRZED ZMIANAMI

W starym systemie każdy poziom definiowałeś w pliku TypeScript. Na przykład poziom pierwszy miał kod który wyglądał tak:

W pliku data, maps, level zero jeden punkt ts, eksportowałeś stałą LEVEL underscore zero jeden równa się createLevelConfig z obiektem zawierającym mapConfig. W mapConfig były waypoints - tablica punktów jak x równa zero, y równa sześć, potem x równa dziesięć, y równa sześć i tak dalej. Były też constructionSpots - miejsca gdzie można budować wieże, jak CS zero jeden na pozycji x równa cztery, y równa osiem.

GameMap renderował wtedy całą mapę jako jeden wielki plik PNG o rozmiarze sześć przecinek dwa megabajta. Ścieżki były rysowane jako brzydkie linie SVG, a waypoints to były zwykłe kolorowe kółka - placeholdery.

PROBLEMY STAREGO SYSTEMU:

Problem pierwszy: Sześć przecinek dwa megabajta tło w jednym pliku PNG - to gigantyczny rozmiar.

Problem drugi: Nie można łatwo edytować map - trzeba otwierać Photoshopa albo GIMP i ręcznie malować na jednym ogromnym obrazie.

Problem trzeci: Linie SVG wyglądają źle - nie ma ładnych tekstur dla ścieżek.

Problem czwarty: Trudno stworzyć nowe mapy - każda wymaga rysowania całego tła od zera.

NOWY SYSTEM - PO ZMIANACH

W nowym systemie tworzysz mapę w programie Tiled Map Editor - to wizualny edytor map. Eksportujesz ją jako plik JSON, na przykład level zero jeden punkt json. Ten plik ma około stu linijek i waży kilka kilobajtów zamiast megabajtów.

Plik JSON zawiera warstwy. Warstwa ground to dane tile - jedynki dla trawy, dwójki dla ziemi. Warstwa path to dane dla ścieżki - zera dla pustych miejsc, piątki dla ścieżki. Warstwa objects to obiekty jak waypoint o współrzędnych x zero y sześć z właściwością order równa zero, albo construction spot o nazwie CS zero jeden.

W kodzie TypeScript importujesz ten JSON i przekazujesz do parsera:

import level zero jeden Json from at slash assets slash maps slash level zero jeden punkt json
import nawiasy klamrowe loadTiledMapFromJson zamknij klamrowe from at slash utils slash tiledLoader

const LEVEL underscore zero jeden underscore TILEMAP równa się loadTiledMapFromJson w nawiasach level zero jeden Json przecinek cudzysłów grasslands zamknij cudzysłów

Potem w createLevelConfig zamiast waypoints i constructionSpots, dajesz tylko tileMap dwukropek LEVEL underscore zero jeden underscore TILEMAP.

GameMap automatycznie renderuje mapę używając małego sprite sheet o rozmiarze około pięćdziesiąt kilobajtów zamiast sześć przecinek dwa megabajta. To sprite sheet pięćset dwanaście na pięćset dwanaście pikseli zawierający wszystkie kafelki po trzydzieści dwa na trzydzieści dwa piksele. TileMapRenderer składa mapę z tych małych kawałków jak z puzzli.

KORZYŚCI NOWEGO SYSTEMU:

Korzyść pierwsza: Dziewięćdziesiąt dziewięć procent redukcja rozmiaru - z sześć przecinek dwa megabajta do około pięćdziesiąt kilobajtów.

Korzyść druga: Tiled Map Editor - wizualne tworzenie map poprzez rysowanie kafelkami zamiast kodowania współrzędnych.

Korzyść trzecia: Ładne tekstury ścieżek z darmowych assetów Kenney punkt nl zamiast brzydkich linii SVG.

Korzyść czwarta: Łatwa edycja i prototypowanie - otwierasz mapę w Tiled, zmieniasz, eksportujesz, gotowe.

LAYOUT SPRITE SHEET:

Sprite sheet ma wymiary pięćset dwanaście na pięćset dwanaście pikseli. To jest szesnaście na szesnaście kafelków, każdy po trzydzieści dwa na trzydzieści dwa piksele.

Rząd zerowy zawiera: Pozycja zero zero - trawa wariant pierwszy. Pozycja jeden zero - trawa wariant drugi. Pozycja dwa zero - trawa wariant trzeci. Pozycja trzy zero - ziemia. Pozycja cztery zero - piasek.

Rząd pierwszy zawiera ścieżki proste: Pozycja zero jeden - ścieżka pozioma. Pozycja jeden jeden - ścieżka pionowa. Pozycja dwa jeden - narożnik lewy górny. Pozycja trzy jeden - narożnik prawy górny. Pozycja cztery jeden - narożnik lewy dolny. Pozycja pięć jeden - narożnik prawy dolny.

Rząd drugi zawiera skrzyżowania: Pozycja zero dwa - skrzyżowanie T w górę. Pozycja jeden dwa - skrzyżowanie T w prawo. Pozycja dwa dwa - skrzyżowanie T w dół. Pozycja trzy dwa - skrzyżowanie T w lewo. Pozycja cztery dwa - skrzyżowanie czterokierunkowe.

Rząd trzeci zawiera dekoracje: Pozycja zero trzy - drzewo wariant pierwszy. Pozycja jeden trzy - drzewo wariant drugi. Pozycja dwa trzy - kamień. Pozycja trzy trzy - krzak. Pozycja cztery trzy - kwiaty.

FAZA C: STWÓRZ PIERWSZĄ MAPĘ - 15 MINUT

KROK C1: NOWY TILESET W TILED

Krok pierwszy: Otwórz program Tiled.

Krok drugi: W menu wybierz Map, potem New Tileset.

Krok trzeci: Ustaw następujące opcje:
Name wpisz: grasslands
Type wybierz: Based on Tileset Image
Image kliknij Browse i wskaż plik: assets slash images slash tiles slash tileset minus grasslands punkt png
Tile width wpisz: trzydzieści dwa
Tile height wpisz: trzydzieści dwa

Krok czwarty: Kliknij OK.

KROK C2: USTAW WŁAŚCIWOŚCI TILE

Krok pierwszy: Kliknij na kafelek trawy w panelu tileset.

Krok drugi: W prawym panelu znajdź sekcję Properties.

Krok trzeci: Kliknij plus, potem Add Property.

Krok czwarty: Dodaj właściwość:
Property name: walkable
Type: bool
Value: false dla trawy

Krok piąty: Dodaj drugą właściwość:
Property name: buildable
Type: bool
Value: true dla trawy

USTAW DLA WSZYSTKICH KAFELKÓW:

Dla trawy: walkable równa się false, buildable równa się true
Dla ścieżki: walkable równa się true, buildable równa się false
Dla drzewa: walkable równa się false, buildable równa się false

KROK C3: NOWA MAPA

Krok pierwszy: W menu wybierz File, potem New, potem New Map.

Krok drugi: Ustaw następujące opcje:
Orientation: Orthogonal
Tile layer format: CSV
Tile render order: Right Down
Map size Width: dwadzieścia tiles
Map size Height: dwanaście tiles
Tile size: trzydzieści dwa na trzydzieści dwa piksele

Krok trzeci: Kliknij OK.

KROK C4: DODAJ WARSTWY

Krok pierwszy: W prawym panelu znajdź sekcję Layers.

Krok drugi: Kliknij plus, potem Add Tile Layer.

Krok trzeci: Dodaj następujące warstwy w tej kolejności:

Warstwa pierwsza: ground - to będzie Tile Layer
Warstwa druga: path - to też będzie Tile Layer
Warstwa trzecia: objects - UWAGA to będzie Object Layer, nie Tile Layer

KROK C5: MALUJ MAPĘ

Krok pierwszy: Wybierz warstwę ground w panelu Layers.

Krok drugi: Wybierz kafelek trawy z panelu tileset.

Krok trzeci: Kliknij ikonę Bucket Fill, albo naciśnij klawisz G.

Krok czwarty: Kliknij na mapie - cała mapa wypełni się trawą.

Krok piąty: Teraz wybierz warstwę path.

Krok szósty: Wybierz kafelki ścieżki - poziome, pionowe i narożniki z panelu tileset.

Krok siódmy: Narysuj ścieżkę od lewej strony mapy do prawej. Pamiętaj: wrogowie będą szli tą ścieżką, więc zaplanuj ją sensownie!

KROK C6: DODAJ WAYPOINTS

Krok pierwszy: Wybierz warstwę objects w panelu Layers.

Krok drugi: Kliknij ikonę Insert Point, albo naciśnij klawisz I.

Krok trzeci: Kliknij na mapie w miejscu gdzie ścieżka ma się rozpoczynać.

Krok czwarty: W prawym panelu Properties ustaw:
Type wpisz: waypoint
Name opcjonalnie wpisz: Start

Krok piąty: Kliknij plus przy Properties, wybierz Add Property:
Property name: order
Type: int
Value: zero

Krok szósty: Powtórz dla kolejnych punktów ścieżki:
Drugi punkt: order równa się jeden
Trzeci punkt: order równa się dwa
Czwarty punkt: order równa się trzy
I tak dalej aż do ostatniego punktu - wyjścia.

BARDZO WAŻNE: Waypoints muszą mieć właściwość order w kolejności zero, jeden, dwa, trzy bez przerw!

KROK C7: DODAJ CONSTRUCTION SPOTS

Krok pierwszy: Nadal na warstwie objects.

Krok drugi: Kliknij Insert Point.

Krok trzeci: Kliknij na mapie gdzie chcesz mieć miejsce do budowy wieży. UWAGA: NIE klikaj na ścieżce! Tylko na trawie obok.

Krok czwarty: W Properties ustaw:
Type: construction
Name: CS minus zero jeden, albo zostaw puste dla automatycznego nazewnictwa

Krok piąty: Powtórz dla około pięciu do ośmiu miejsc budowy rozmieszczonych strategicznie wokół ścieżki.

KROK C8: EKSPORT DO JSON

Krok pierwszy: W menu wybierz File, potem Export As.

Krok drugi: W Format wybierz: JSON map files, gwiazdka punkt json

Krok trzeci: Zaznacz checkboxy:
Checkbox pierwszy: Embed tilesets
Checkbox drugi: Detach templates

Krok czwarty: Zapisz jako: assets slash maps slash level minus zero jeden minus test punkt json

CZĘŚĆ PIĄTA: ROZWIĄZYWANIE PROBLEMÓW

PROBLEM PIERWSZY: MAP SIZE MISMATCH

Komunikat błędu:
Error dwukropek Map size mismatch punkt Expected dwadzieścia razy dwanaście przecinek got szesnaście razy dziesięć

Rozwiązanie:

Krok pierwszy: Otwórz mapę w programie Tiled.

Krok drugi: W menu wybierz Map, potem Map Properties.

Krok trzeci: Sprawdź pola Width i Height. Powinny być: Width dwukropek dwadzieścia, Height dwukropek dwanaście.

Krok czwarty: Jeśli wartości są inne - zmień je albo stwórz nową mapę z poprawnymi wymiarami.

PROBLEM DRUGI: MISSING GROUND LAYER

Komunikat błędu lub ostrzeżenia:
Warning dwukropek Missing required layer dwukropek ground

Rozwiązanie:

Krok pierwszy: Otwórz mapę w programie Tiled.

Krok drugi: W prawym panelu znajdź sekcję Layers.

Krok trzeci: Sprawdź czy jest warstwa o nazwie dokładnie ground. Nazwa musi być pisana małymi literami! Case-sensitive!

Krok czwarty: Jeśli warstwy ground nie ma - kliknij plus, wybierz Add Tile Layer, nazwij ją ground.

PROBLEM TRZECI: WAYPOINTS OUT OF ORDER

Symptom: Wrogowie skaczą losowo po mapie zamiast iść ścieżką w logicznej kolejności.

Rozwiązanie:

Krok pierwszy: Otwórz mapę w programie Tiled.

Krok drugi: Wybierz warstwę objects w panelu Layers.

Krok trzeci: Kliknij na każdy waypoint - to są kropki na mapie.

Krok czwarty: Sprawdź w prawym panelu Properties czy każdy waypoint ma właściwość order.

Krok piąty: Upewnij się że wartości order to: zero, jeden, dwa, trzy, cztery i tak dalej bez dziur! Nie może być: zero, jeden, trzy, pięć - to jest źle. Musi być ciągła sekwencja.

PROBLEM CZWARTY: TILES NOT RENDERING

Symptom: Mapa jest całkowicie czarna albo nie widać żadnych kafelków.

Rozwiązanie:

Krok pierwszy: Sprawdź czy plik tileset minus grasslands punkt png istnieje. W terminalu wpisz:
ls assets slash images slash tiles slash tileset minus grasslands punkt png

Krok drugi: Sprawdź konsolę w Metro bundler - szukaj ostrzeżeń:
WARN dwukropek Tileset not found dwukropek at slash assets slash images slash tiles slash tileset minus grasslands punkt png

Krok trzeci: Jeśli plik brakuje - pobierz go z Kenney punkt nl albo stwórz prosty placeholder jak opisano w części drugiej.

Krok czwarty: Sprawdź czy eksport z Tiled zawiera embedded tileset. W Tiled przy eksporcie musi być zaznaczony checkbox: Embed tilesets.

PROBLEM PIĄTY: CONSTRUCTION SPOTS NOT CLICKABLE

Symptom: Nie można kliknąć na construction spot, nie działa budowanie wież.

Rozwiązanie:

Krok pierwszy: Sprawdź czy construction spot NIE jest umieszczony na ścieżce. Spot musi być na trawie albo ziemi, nie na path tiles!

Krok drugi: Construction spots muszą być na kafelkach które mają właściwość buildable równa się true. To są kafelki typu grass lub dirt.

Krok trzeci: W Tiled sprawdź properties kafelka pod spotem - właściwość buildable musi być true.

PROBLEM SZÓSTY: ENEMIES WALK THROUGH TOWERS

Symptom: Wrogowie przechodzą przez miejsca gdzie stoją wieże.

Rozwiązanie:

To nie jest błąd! To jest prawidłowe zachowanie. Wrogowie idą tylko ścieżką wyznaczoną przez waypoints. Wieże są budowane poza ścieżką na construction spots. Wrogowie nie schodzą ze ścieżki, więc nigdy nie przechodzą przez wieże.

Jeśli wrogowie faktycznie schodzą ze ścieżki i chodzą losowo - sprawdź problem trzeci: waypoints out of order.
